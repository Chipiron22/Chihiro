# バドミントン ロードマップ

大会から逆算して、毎日の練習・試合・動画を記録するアプリです。サーバー不要で、`app/index.html` を開くだけで動きます。

## 主な機能
- **目標(逆算プラン)**: 大会の日付を登録すると、基礎づくり期・技術強化期・実戦期・調整期に分けた計画と「やること」を自動作成
- **練習の記録**: 日付、時間、メニュー、調子、気づき、動画
- **試合の記録**: スコア(最大3ゲーム)、勝敗の自動判定、良かった点、次の課題、動画
- **ホーム**: 大会までの日数、今の期間、今週の練習グラフ、連続練習日数
- **動画分析**: スロー再生・コマ送り、端末内の姿勢測定(ひじ・膝・体の傾きの角度と目安コメント。複数人が写る場合は測る人を選択)、フォーム写真の保存、Claudeへの相談(写真と相談文を共有)
- **参考動画の検索リンク**: 目標の「やることリスト」とAIコーチの「次の練習メニュー」から、YouTube・Googleの検索結果へ移動。見つけたリンクはメモつきで保存
- **AIコーチ(任意)**: 写真をAIに送り、改善点とおうちでできる練習を提案。月の利用額に上限あり(`worker/README.md`)
- **バックアップ**: JSONの書き出しと読み込み

## 使い方
1. `app/` を静的サイトとして公開します(例: GitHub Pages)。
2. スマホで開き、「ホーム画面に追加」を選ぶとアプリのように使えます。

姿勢測定は初回のみ、MediaPipe(CDN)の読み込みで通信が必要です。測定は端末内で行い、動画は外部に送信しません。

データと動画は端末内(localStorage / IndexedDB)にのみ保存されます。
